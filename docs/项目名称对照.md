# 项目名称对照

与 AI / 同事沟通时，请使用下列**中文简称**；磁盘目录与 Git 仓库名保持不变。

| 中文简称 | 目录 / 仓库 | 说明 |
|----------|-------------|------|
| **源码版** | `EasyManufacture.Net10/`（主仓库 IntelligentFactory） | 全量源码、迁移脚本、Reactor 混淆源头 |
| **公版** | `APSNET10/`（GitHub: `liaoshanghua/APSNET10`） | 仅 Api 源码 + `lib/` 混淆 DLL，对外给同事 |

## 同步关系

```text
源码版  Release 编译 → Reactor 混淆 → Sync-ObfuscatedLibs.ps1 → 公版/lib/
```

维护脚本：`scripts/Export-ApsNet10Repo.ps1`、`APSNET10/scripts/Sync-ObfuscatedLibs.ps1`
