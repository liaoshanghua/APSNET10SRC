# 项目名称对照

与 AI / 同事沟通时，请使用下列**中文简称**；磁盘目录与 Git 仓库名保持不变。

完整协作规则以公版文档为准：`../APSNET10/docs/项目名称对照.md`。

| 中文简称 | 目录 / 仓库 | 说明 |
|----------|-------------|------|
| **公版** | `APSNET10/`（GitHub: `liaoshanghua/APSNET10`） | Api 宿主源码（同事可改）+ `lib/` |
| **源码版** | `EasyManufacture.Net10/`（主仓库 IntelligentFactory） | 全量业务源码、混淆源头 |

## 同步关系（摘要）

| 改什么 | 以谁为准 | 方向 |
|--------|----------|------|
| **Api**（含 Legacy APSData / SetDt） | **公版** | 公版 → 源码版（`Sync-ApiToNet10.ps1` / `Import-ApiFromApsNet10.ps1`） |
| **业务 lib** | **源码版** | 源码版 → 公版 `lib/`（`Sync-LibToApsNet10.ps1`） |

**不要**用「源码版 Export 覆盖公版 Api」；Api 以公版为准（公版含其他同事代码）。

## 对话示例

- 「在 **公版** 改 APSData，再同步到 **源码版**」
- 「把混淆 DLL 从 **源码版** 推到 **公版** lib」
