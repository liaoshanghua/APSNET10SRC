# EasyManufacture.Net10 项目结构说明

## 1. 解决方案总览

```
源码版本/
├── EasyManufacture.Net10/          # 类库 + 联调 Api（开发主仓）
│   ├── src/
│   │   ├── EasyManufacture.Api/           # Web 宿主（联调：ProjectReference）
│   │   ├── EasyManufacture.Application/     # 服务接口（IConfigService、IApsDataService 等）
│   │   ├── EasyManufacture.Domain/          # 配置项、DTO
│   │   ├── EasyManufacture.Infrastructure/  # 数据访问、APS Legacy、定时任务
│   │   └── EasyManufacture.Licence/         # AppInfo、授权、SystemLog
│   ├── packages/                   # NuGet 本地包（Pack-Libraries.ps1 输出）
│   └── scripts/                    # 迁移/打包脚本
│
├── EasyManufacture.Api/            # 独立交付宿主（NuGet 引用，见该目录 README）
├── EasyManufacture.Web/              # 旧 .NET Framework 4.8 站点（对照源）
└── EasyManufacture.Core/             # 旧核心库（APSCore.cs 等对照源）
```

## 2. 请求链路（POST /APSAPI/APSData）

```
HTTP 请求
  → EasyManufacture.Api/Controllers/APSAPIController.APSData()
  → IApsDataService (ApsDataService)
       ├─ LegacyWeb:ForwardApsData=true → 转发旧 EasyManufacture.Web
       └─ 本地 → ApsCoreEngine.RunAPSData()          [ApiCustom.cs]
            ├─ ApplyApsDataDicHooks()                 [YrfDicHooks.cs，仅 6 个 YRF dic]
            └─ APSData()                                [LegacyCore.cs，EnableLegacyApsCoreSource=true]
                 └─ MSSQLCore.LegacyFull.cs 构建 SQL、SetDt/setRowDetail 钩子
```

其余 Action（如 `DeliveryPlan`、`SaveData10075`）：

```
APSAPIController.LegacyStubs / LegacyCoreStubs
  → InvokeLegacyAsync()
  → ApsApiLegacyDispatcher（反射 ApsCoreEngine 同名 public 方法）
  → ApsCoreEngine.LegacyApi.cs / LegacyCore.cs
```

## 3. 旧版与新版对应关系

| 旧版 (.NET 4.8) | 行数约 | 新版位置 |
|-----------------|--------|----------|
| `EasyManufacture.Web/Controllers/APSAPIController.cs` | 29287 | `ApsCoreEngine.LegacyApi.cs`（27531 行）+ Api 层路由 |
| `EasyManufacture.Core/MvcControl/APSCore.cs` | 28126 | `ApsCoreEngine.LegacyCore.cs`（28091 行，脚本生成） |
| `APSAPIController : APSCore` 继承 | — | 合并为 `partial class ApsCoreEngine` |
| `APSAPIController.override APSData()` 的 dic switch | ~700 行 | **未完整迁移**；Net10 仅 YrfDicHooks 6 个 case |

## 4. ApsCoreEngine 分部类文件索引

编译开关见 `EasyManufacture.Infrastructure.csproj` 中 `EnableLegacyApsApiSource` / `EnableLegacyApsCoreSource`。

| 文件 | 何时编译 | 说明 |
|------|----------|------|
| `ApsCoreEngine.Host.cs` | Core=false | 精简模式：构造函数、BodyJson、EF 注入 |
| `ApsCoreEngine.Body.cs` | Core=false | 精简 GetConfig / SaveData（自 APSCore 提取） |
| `ApsCoreEngine.ApsData.cs` | Core=false | 精简 APSDataCore() |
| `ApsCoreEngine.ApsDataFields.cs` | Core=false | setWhere、列配置字段 |
| `ApsCoreEngine.ApsDataPostProcess.cs` | Core=false | 查库后合计行、颜色等后处理 |
| `ApsCoreEngine.ApiCustom.cs` | 始终 | RunAPSData() 入口、ApplyApsDataDicHooks 调用 |
| `ApsCoreEngine.YrfDicHooks.cs` | Api=false 时排除 | 盈瑞丰 6 个 dic 的 SetDt 挂载 |
| `ApsCoreEngine.YrfExtensions.cs` | Api=true 时排除 | 精简模式 YRF SetDt 实现 |
| `ApsCoreEngine.ApiBasic.cs` | 始终 | GetGroupName、GetDataSource |
| `ApsCoreEngine.Organize.cs` | Api=true 时排除 | GetOrganize、GetOrgData |
| `ApsCoreEngine.Menus.cs` | Api=true 时排除 | GetMenus |
| `ApsCoreEngine.K3Cloud.cs` | 始终 | 金蝶调拨、orderToStart |
| `ApsCoreEngine.LegacyApi.cs` | Api=true | **旧 APSAPIController 全文**（DeliveryPlan 等 120+ Action） |
| `ApsCoreEngine.LegacyCore.cs` | Core=true | **旧 APSCore 全文**（GetConfig/SaveData/APSData 主逻辑） |
| `ApsCoreEngine.LegacySharedState.cs` | Core=true | LegacyCore 共用字段 |
| `ApsCoreEngine.DependencyInjection.cs` | Core=true | LegacyCore 专用构造（替代 Host.cs） |
| `ApsCoreEngine.LegacyMvcCompat.cs` | 始终 | JsonResult、FormResult 等 MVC 兼容 |
| `ApsCoreEngine.LegacyHttpShim.cs` | 始终 | IHttpContextAccessor、Request 兼容 |
| `ApsCoreEngine.PdfWatermark.cs` | 始终 | PDF 水印（ISGO 等） |
| `MSSQLCore.cs` | Core=false | 精简 SQL 构建 |
| `MSSQLCore.LegacyFull.cs` | Core=true | 旧 MSSQLCore 全量 |

## 5. APSAPIController 分部类（Api 项目）

| 文件 | 说明 |
|------|------|
| `APSAPIController.cs` | 核心路由：GetConfig、SaveData、APSData、SSO、GetMenus 等（显式实现） |
| `APSAPIController.LegacyStubs.cs` | 旧 Web Controller 中的 Action 路由（反射 LegacyApi） |
| `APSAPIController.LegacyCoreStubs.cs` | 旧 APSCore 中的 public 方法路由（脚本 Generate-ApsApiStubs.ps1 生成） |

## 6. 脚本

| 脚本 | 作用 |
|------|------|
| `scripts/Migrate-ApsCore.ps1` | 从 `EasyManufacture.Core/APSCore.cs` 生成 `LegacyCore.cs` |
| `scripts/Pack-Libraries.ps1` | 打包 Domain/Application/Licence/Infrastructure 到 `packages/` |
| `scripts/Generate-ApsApiStubs.ps1` | 扫描 ApsCoreEngine 公共方法，生成缺失的 Controller 路由 |

## 7. 已知差异（迁移待办）

1. **APSData dic switch**：旧 `APSAPIController.override APSData()` 内 100+ 个 `case dicID` 未迁入；非 YRF dic 的 SetDt 可能不生效。
2. **APSAPIController.APSData() 大 switch**：旧 Web Controller 内 dic 前置逻辑 vs `YrfDicHooks` 仅 6 个。
3. 复杂 dic 可临时使用 `LegacyWeb:ForwardApsData=true` 转发旧站。

## 8. 配置项速查

| appsettings 节点 | 说明 |
|------------------|------|
| `ConnectionStrings:MSSQLConnectionString` | 主库连接串 |
| `App:PushType` | YS / YRF / ISGO / EK 等，控制定时任务 |
| `App:SSOUrl` | `项目‖地址‖密钥`（分隔符 Unicode ‖） |
| `LegacyWeb:ForwardApsData` | true 时 APSData 转发旧 Web |
| `LegacyWeb:ForwardAllApsApi` | true 时未本地实现的 Action 转发旧 Web |
| `Cors:Origins` | 生产 CORS 白名单 |
