# 数据库还原与清空 APS 业务表（按表名前缀）

从 `.bak` 还原 SQL Server 库后，自动 **TRUNCATE** 所有 **表名以指定前缀开头** 的 dbo 用户表（保留表结构，删除全部数据）。

## 匹配规则

| 前缀 | 示例（会被清空） |
|------|------------------|
| `APS_Order` | APS_Order、APS_OrderDetail、APS_OrderPlanImport … |
| `APS_Material` | APS_Material、APS_Material_TEMP … |
| `APS_PO` | APS_PO、APS_POImport … |
| `APS_ProcessMaterial` | APS_ProcessMaterial、APS_ProcessMaterialImport … |
| `APS_ProcessPlan` | APS_ProcessPlan、APS_ProcessPlanHistory … |
| `APS_SalesOrder` | APS_SalesOrder、APS_SalesOrderDetail … |

存储过程会在执行后 **返回实际 TRUNCATE 的表名列表**。

脚本：`docs/sql/P_APS_TruncateCoreTablesAfterRestore.sql`  
命令行：`scripts/Restore-ApsDatabase.ps1`  
图形界面：启动 APS 后，托盘右键或状态窗口 **还原/清空库**

## 使用前

1. **还原备份**前须停止 APS（图形界面选「还原」时会自动退出）；**仅清表**可不停服务。
2. 还原模式需本机已安装 **sqlcmd**（PowerShell 脚本用）。
3. `.bak` 路径须为 **SQL Server 所在机器** 可访问的路径。

## 图形界面（推荐）

用 `APS-启动.bat` 正常启动后：

| 入口 | 操作 |
|------|------|
| 任务栏托盘图标 → 右键 | **数据库还原 / 清空业务表** |
| 状态窗口 | **还原/清空库** |

- **仅清空前缀表**：APS 可继续运行，直接在当前窗口执行。
- **从 .bak 还原**：会弹出 PowerShell 执行还原，APS 自动退出，完成后请重新运行 `APS-启动.bat`。

## 命令行还原 + 清空

```powershell
cd EasyManufacture.Net10

.\scripts\Restore-ApsDatabase.ps1 `
  -BackupPath "D:\Backup\APS20260301.bak" `
  -Confirm
```

连接串默认读 `src/EasyManufacture.Api/appsettings.json`，也可用环境变量 `APS_CONNECTION_STRING`。

## 常用参数

| 参数 | 说明 |
|------|------|
| `-BackupPath` | `.bak` 完整路径 |
| `-SkipRestore` | 不还原，仅按前缀清空表 |
| `-SkipTruncate` | 只还原，不清空 |
| `-Confirm` | 跳过交互确认（须输入 YES 时不用） |

## 示例

```powershell
# 库已还原，只清空匹配前缀的表
.\scripts\Restore-ApsDatabase.ps1 -SkipRestore -Confirm

# 只还原，保留备份中的业务数据
.\scripts\Restore-ApsDatabase.ps1 -BackupPath "D:\Backup\APS.bak" -SkipTruncate -Confirm
```

## 手动 SQL

```sql
-- 创建/更新存储过程
-- 执行 docs/sql/P_APS_TruncateCoreTablesAfterRestore.sql

EXEC dbo.P_APS_TruncateCoreTablesAfterRestore;
-- 结果集列为 TruncatedTable，列出已清空的表
```

## 预览将清空的表（不执行 TRUNCATE）

```sql
SELECT t.name
FROM sys.tables t
INNER JOIN sys.schemas s ON s.schema_id = t.schema_id
WHERE s.name = N'dbo'
  AND (
        t.name LIKE N'APS_Order%'
     OR t.name LIKE N'APS_Material%'
     OR t.name LIKE N'APS_PO%'
     OR t.name LIKE N'APS_ProcessMaterial%'
     OR t.name LIKE N'APS_ProcessPlan%'
     OR t.name LIKE N'APS_SalesOrder%'
  )
ORDER BY LEN(t.name) DESC, t.name;
```

## 注意

- 还原使用 `WITH REPLACE`，会覆盖同名数据库。
- 清空前会临时关闭相关外键约束，完成后恢复。
- 仅处理 **dbo** 架构下的用户表。
